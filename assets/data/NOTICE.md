# Iran administrative divisions data

The province, county, and city records in `iran-locations.json` are derived from
the `sajaddp/list-of-cities-in-Iran` project, release 3.1.2, whose stated source
year is 1404 (Solar Hijri):

https://github.com/sajaddp/list-of-cities-in-Iran

Only identifiers, names, and parent relationships needed by the address form
are included. The source project is licensed under GNU GPL v3.0; a copy of that
license is included as `LICENSE-GPL-3.0.txt`.
